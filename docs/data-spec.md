# Data you need to provide (per movie)

Folder: `data/movies/<movie_id>/`. See `data/movies/demo/` for a full example.

```
<movie_id>/
├─ movie.json               required
├─ video.mp4                required (git-ignored, share separately)
├─ subtitles.srt            required
├─ characters.json          required
├─ synopsis.txt             optional — background notes, fed to the summarizer
├─ scene_marks.json         optional — [start_s, ...] hand-picked scene boundaries
├─ knowledge/               generated by preprocess (can be hand-edited)
│  ├─ scenes.json
│  └─ character_states.json
└─ characters/<id>/         generated: face.png, voice_ref.wav
```

## movie.json
```json
{ "id": "mymovie", "title": "My Movie", "language": "zh", "video": "video.mp4", "subtitles": "subtitles.srt" }
```
`language` = main spoken language (ISO-639-1), used for transcribing the voice clip.

## subtitles.srt
Standard SRT, UTF-8. **Speaker names help a lot**: start a line with `NAME:` / `NAME：` or `[NAME]`
where NAME matches a character's `id`, `name` or one of its `aliases`. Unattributed lines still work.

```
12
00:01:05,000 --> 00:01:09,000
王小明：我们今晚就走。
```

## characters.json
```json
[
  {
    "id": "xiaoming",
    "name": "王小明",
    "aliases": ["小明", "Xiaoming"],
    "bio": "One-paragraph background as of the START of the movie (no spoilers).",
    "personality": "Traits.",
    "speech_style": "Tone, catchphrases, dialect.",
    "delivery_profile": "expressive",
    "relationships": { "other_id": "how they relate at the start" },
    "face_at_s": 754.2,
    "voice_clip": [812.0, 829.5],
    "voice_ref_text": "optional exact transcript of the clip"
  }
]
```

- **face_at_s**: a moment where the face is frontal, sharp, well lit, not covered. Or put your
  own `characters/<id>/face.png` and set `"face_image": "face.png"`.
- **voice_clip**: 5–30 s where only this character speaks, ideally little music. The pipeline
  removes music with demucs, but cleaner input = better clone.
- **delivery_profile**: optional `expressive` maps scene mood and speech style to explicit delivery
  controls. Use `subtle` for naturalistic characters; only clear cues in the current line receive
  emotion tags, while the cloned voice and persona prompt carry the performance. When omitted, a
  project character preset is used when available, then `expressive`.
- `voice_id` and `face_image` are filled in by the pipeline.

## Generated: knowledge/scenes.json
```json
[{ "id": "s000", "start": 0, "end": 60, "characters_present": ["alice", "bob"],
   "summary": "...", "key_events": ["..."], "lines": [{ "start": 3, "end": 6, "text": "...", "speaker": "bob" }] }]
```

## Generated: knowledge/character_states.json
```json
[{ "character_id": "alice", "t": 60, "goals": "...", "stance": "...", "emotion": "...",
   "relationships": { "bob": "..." }, "knows": ["..."] }]
```

Hand-editing these is the fastest way to improve quality for the demo — especially
`characters_present` and key checkpoints.
